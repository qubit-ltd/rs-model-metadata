## 交互决定核对

| 确认批次 | 已合并的决定 |
| --- | --- |
| 1～5 | 只识别当前声明可见的 derive；真实 Id 类型别名合法；opaque 不隐藏模型身份；局部和完整图错误分阶段；unique 按文本能力决定大小写参数 |
| 6～10 | ModelImpl 复用完整 impl 反射边界；自动输出遵守脱敏；codec 类型引用也需注册；validator 按稳定 ID 声明；完整签名归新设计 |
| 11～15 | 显式 codec 与 canonical 相同合法；indexed 的 filter 场景保留但不在本库生成；基础 const 泛型；Unicode case folding；reference.path 支持父对象并统一斜杠 |
| 16～20 | 无 ID 类型和具体泛型可作解析入口；无 ID 泛型保留模型定义关联；可选/包装/集合 reference；Serde 不绕过脱敏；skip 不限制字段形状，按 rs-redact 的启用/关闭策略输出 |
| 21～25 | no_redact 不取消嵌套类型自身输出策略；类型与使用位置约束叠加；validator 每项依赖独立 path/property 并支持父对象；允许重复 validator ID；Enum payload 允许显式 reference，但 Value 纯值闭包不能包含它 |

| 27～29 | 保留显式 indexed 与隐含原因共存时报错；保留 Set unique_items 冗余错误及固定数组长度约束禁令；保留 Eq/Hash 开关联动 |
| 30～31 | 方法可显式退出 Property 组装但仍保留反射；getter 不新增领域属性；符合规则且无同名字段的 getter 自动成为 computed Property，不提供 computed 标记 |

## 路径与职责的最终区别

| 声明 | 对象导航 | 属性选择 | 本库与消费者的分工 |
| --- | --- | --- | --- |
| reference | path 用 `/`、支持 `..`；省略表示未指定复用绑定 | property 使用普通点分隔路径；省略选择完整 Entity | metadata 记录绑定语义，跨 reference 按完整 Entity 绑定理解；实例复用和父级缺失回退由消费者处理 |
| validator 依赖 | 每项依赖独立 path；用 `/`、支持 `..`；省略表示当前对象 | 每项独立 property，使用点分隔路径 | metadata 保存结构化路径、选择和声明起点；消费者提供上下文，不自动获取未提供的完整 Entity |

两者的 `..` 都不把集合本身算作额外领域父对象。父实例无法从类型 registry 唯一确定时保留上下文依赖，不能直接拒绝声明。
validator 字段及 selector 声明从字段所属对象出发；元素类型内部字段的声明从元素对象出发。

## 本轮编辑性收尾

- 需求状态改为冻结候选，没有提前宣告整体确认。
- 历史讨论不再被描述为不会变化的唯一需求来源；本轮已确认修订优先。
- 区分反射注册与 ModelRegistry 的稳定 ID 注册，消除无 ID 泛型与“禁止匿名注册”的文字冲突。
- QueryMetadata 只包含声明和已解析结构，不构造产品 filter 计划。
- Projection producer 的声明来源由 resolver 检查，实际生成 ID 由调用消费者检查，metadata 查询不执行 getter。
- validator 的静态依赖检查统一受显式上下文能力限制。
- 纠正相等 decimal 边界的表述：任一端排他都会产生空区间；同时存在 precision/scale 时才比较二者。
- Enum ordinal 明确为当前声明顺序，不能作为跨版本稳定编码。
- ModelId 动态输入示例采用已要求的 ModelIdBuf::parse；删除注册查询示例中的占位注释。
- 需求与设计的同步是重构交付条件，不把尚未重写的设计或用户指南误报为已对齐。
